# NORM Engineering - Corporate Website

This is the official website for **NORM Engineering**, a professional mining exploration and engineering consultancy firm. Built with **React**, **TypeScript**, and **Tailwind CSS**.

## 🏗️ About NORM Engineering

NORM Engineering is an international independent engineering firm established in 2021, providing services in exploration and mining in accordance with international standards and procedures. We deliver safe, ethical, and sustainable engineering solutions following accepted environmental, social, and governance principles.

https://norm-engineering.com

## ✨ Features

- Modern, responsive design
- Multi-page application with React Router
- Smooth animations and transitions
- Blog system for industry updates
- Project portfolio showcase

- Mobile-optimized interface
- SEO-friendly structure

## 📄 Page Structure

- **Hakkımızda (Home)** - Hero section with company overview and statistics
- **Hizmetlerimiz (Services)** - Detailed service offerings
  - Maden Arama (Mineral Exploration)
  - Jeoloji ve Kaynak Yönetimi (Geology & Resource Management)
  - Açık Ocak ve Yeraltı Tasarımı (Open Pit & Underground Design)
  - Proje Değerlendirme (Project Evaluation)
- **Proje Referanslarımız (Project References)** - Portfolio of completed projects
- **Blog** - Industry news and technical articles
- **İletişim (Contact)** - Contact form and company information

## 🚀 Tech Stack

- ⚛️ **React 18**
- 🟦 **TypeScript**
- 🎨 **Tailwind CSS**
- 🛣️ **React Router v6**
- 🎭 **Ant Design Icons**
- 📊 **React CountUp** - Animated statistics
- 👁️ **React Intersection Observer** - Scroll animations
- 🗄️ **Sanity CMS** (planned integration)

## 🛠️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/your-username/norm-engineering-website.git
cd norm-engineering-website
```

### 2. Install dependencies

```bash
npm install
# or
yarn install
```

### 3. Start the development server

```bash
npm start
# or
yarn start
```

The application will open at [http://localhost:3000](http://localhost:3000)

### 4. Build for production

```bash
npm run build
# or
yarn build
```
